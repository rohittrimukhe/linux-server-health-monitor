LRS Vitals

Install guide - one page

What you need

A Red Hat family server (RHEL, Oracle Linux or Rocky, versions 7 to 9) with Python 3.6 or newer and OpenSSL, and root access. LRS Vitals only reads from the server. It never restarts services or changes databases.

1. Install

sudo dnf install ./lrs-vitals-1.4.0-2.noarch.rpm

This adds the commands vitals, systemhealth and healthcheck (all the same program) and a short getting-started guide.

2. First-time setup

sudo vitals

The first run scans the server and shows a few setup pages, one at a time: company and customer details, email, schedules and real-time monitoring. Parts that do not exist on the server (for example KVM) are left out of the reports automatically.

3. What happens by itself

ReportWhenWhat it shows
DailyMonday to Saturday, 09:00Status, checklist, last 24 hours of CPU, memory, network, disks, databases, folders
WeeklySunday, 12:00The daily view over 7 days, growth by date, capacity forecast, comparison with last week
MonthlyDay 1, 10:00A summary and a comprehensive report with inventory, services and day-by-day growth
Server scanSunday, 02:00Finds new software (databases, KVM, backup tools) and adds it to the checks

Reports are saved in /var/lib/lshme/reports/ and emailed once email is set up. Times can be changed in vitals > Settings.

4. Set up email (recommended)

In vitals > Settings > smtp, enter the mail server, port, sender and recipients. Put the password in the credentials file (root only). Test with:

sudo vitals run --report-type daily --email

5. Switch on live monitoring and alerts

sudo vitals watch install

A light watcher (about 0.02% of one CPU and 30 MB) checks CPU, memory, disks and services every minute and sends alerts by email, Slack, Teams, a webhook or syslog. It also feeds the 24-hour graphs in the reports.

6. Open the web dashboard (optional)

sudo vitals web install

Sign in with a Linux user name and password. root and members of wheel have full access; other users are read-only. Keep TLS switched on for network access.

Upgrading: sudo dnf upgrade ./lrs-vitals-NEW.rpm. Your settings in /etc/lshme are kept. Removing: sudo dnf remove lrs-vitals removes the program and timers and keeps your settings.
